# Biblioteca Digital UniFECAF

Projeto acadêmico de Design Web desenvolvido com HTML5 semântico e CSS3, com layout responsivo para desktop, tablet e smartphone.

## Estrutura

```text
biblioteca-unifecaf/
├── index.html
├── css/
│   └── style.css
├── assets/
│   └── imagens/
└── README.md
```

## Como visualizar localmente

1. Extraia a pasta do projeto.
2. Abra `index.html` em um navegador moderno.
3. Para editar, abra a pasta em um editor como Visual Studio Code.

O site utiliza fontes do Google Fonts quando há conexão com a internet. Se as fontes não carregarem, serão utilizadas fontes alternativas instaladas no sistema.

## Publicar com GitHub Pages

1. Entre em https://github.com e crie um repositório público, por exemplo `biblioteca-unifecaf`.
2. Envie todos os arquivos e pastas deste projeto para a raiz do repositório. O arquivo `index.html` precisa ficar na raiz.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`; salve.
6. Aguarde a publicação e copie o endereço público informado pelo GitHub Pages.

## Publicar com Netlify

1. Entre em https://app.netlify.com/.
2. Escolha a opção de adicionar um novo site por deploy manual.
3. Arraste a pasta do projeto extraída (a pasta que contém `index.html`) para a área de deploy.
4. Após o processamento, copie o endereço público do site.

## Observações importantes para a entrega

- Os cards e os nomes de livros usados na interface são exemplos visuais, não um catálogo real conectado ao sistema da instituição.
- Os links de navegação levam às seções correspondentes desta página. Não há login, pesquisa dinâmica ou integração com catálogo institucional, pois o escopo é uma primeira interface estática em HTML e CSS.
- Antes de entregar, teste o site em desktop e smartphone, faça capturas de tela das duas versões e inclua-as no relatório teórico.
- O trabalho também solicita relatório em PDF, link público do site, link do repositório e vídeo pitch. Esses itens precisam ser preparados e enviados separadamente.
